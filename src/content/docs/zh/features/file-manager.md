## 如何进入
点击任何已配置的 SSH 主机旁边的 "文件管理" 按钮, 即可进入文件管理界面.

## 支持的功能
- **Explorer (文件浏览)**:
  - 创建新文件和文件夹.
  - 重命名和删除文件/文件夹.
  - 在远程目录内进行拖拽移动.
  - 从本地上传文件到远程, 以及从远程下载文件到本地.
- **内置 Editor (代码编辑器)**:
  - 支持多标签页, 可同时编辑多个文件.
  - 支持多种编程语言的语法高亮.
  - 支持编码切换和多行编辑功能.
- **图片查看器**: 直接预览远程服务器上的图片, 无需下载到本地.
