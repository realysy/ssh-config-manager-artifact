## Free Trial
Enjoy a 30-day free trial. After the trial period, you can pay to continue using the software. Your SSH data is natively stored in the universal `~/.ssh/config` format, meaning you can retain and use it directly without any complex export process. Please refer to the [SSH Group Management](../features/ssh-management/ssh-group-management.md) documentation for the exact location of these configuration files.
