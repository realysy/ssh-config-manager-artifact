## ✨ v1.3.0 新特性

SSH Config Manager v1.3.0 发布，优化了终端工作流效率、文件管理灵活性，并扩展了支付选项。

### 🖥️ 更智能的终端：会话持久化与命令历史

终端体验在本版本中迎来重大升级。SSH 断开连接后，**终端窗口和标签页不再自动关闭**，你可以随时回顾之前的命令执行记录和输出结果。结合新增的 **SSH 命令历史**功能，只需按下 `Up` 键即可快速重新执行之前的命令，大幅提升重复性操作的效率。

![终端会话持久化](@/assets/screenshots/zh/press-up-key-to-reconnect.png)

### 📂 多文件选择与批量下载

文件管理器现在支持按住 **Ctrl** 或 **Shift** 键同时选中多个文件和文件夹，右键一键批量下载全部选中内容，告别逐个操作的繁琐。这在导出日志、配置文件或批量下载远程服务器上的资源时尤其实用。

![多文件选择](@/assets/screenshots/zh/file_manager-multi-select-download-all.png)

### 💳 新增 Creem 支付方式

我们集成了 **Creem** 作为新的支付服务商。现在你可以通过**信用卡/借记卡、Apple Pay、支付宝**等多种方式完成支付。此举进一步丰富了我们的支付渠道，更好地服务全球不同地区的用户。

![Creem 支付](@/assets/screenshots/zh/activation_creem-payment.png)

### 🛠️ 文件管理器体验优化

文件管理器在本次更新中获得了多项界面交互优化：

- **工具栏按钮重新设计** —— 图标更清晰，视觉层级更合理
- **点击/双击行为改进** —— 文件树与文件列表视图之间的交互更加符合直觉
- **大文件传输通知优化** —— 传输进度反馈更清晰明了

### 🔧 底层改进

- **API 速率限制提升** —— 重度用户的使用体验更加流畅
- **登录页增加"记住我"选项** —— 会话持久化，方便日常使用
- **激活页面视觉增强** —— 首次启动体验更加精致
- **CI/CD 编译时间优化** —— 从 29 分钟缩短至 7 分钟，大幅提升开发迭代速度
